Relay 为两台电脑提供统一的 Codex 工作台。支持局域网直连，也支持通过自建 Cloudflare Workers 中继进行异地连接。代码、运行环境和 Codex 登录信息留在执行任务的电脑上。

## 功能

- **双向操作**：一次配对，两端均可选择共享本机或操作远端。
- **项目与会话**：折叠项目分组、搜索历史、新建和继续对话，支持会话归档与恢复。
- **消息排队**：任务运行时继续输入，待发消息按顺序发送，支持编辑、移除和暂停后继续。
- **专注结果**：中间说明和工具调用可收起，展示每轮处理用时。
- **@ 引用**：搜索执行电脑上的项目文件，选择技能或可用应用。
- **审批与控制**：处理命令、文件修改和补充输入请求，选择模型与推理强度，停止任务。
- **加密连接**：双方确认设备身份，密钥保存在系统凭据管理器，可随时暂停共享。
- **应用更新**：启动后检查新版本，支持手动检查、下载进度和签名验证，确认后安装并重启。
- **桌面体验**：可收起的设备栏、自定义标题栏、浅深色主题和文件变更检查器；关闭窗口收起到系统托盘，通过托盘菜单退出。

## 快速开始

1. 从 [Releases](https://github.com/beiyuan324/agent-relay/releases/latest) 下载安装包，在两台 Windows 电脑上安装 Relay；也可按[开发指南](./docs/开发指南.md)从源码启动。
2. 在需要执行任务的电脑上安装并登录 Codex。Relay 自动检测已有安装，也支持手动指定路径。
3. 在一端点击 **添加设备 → 创建邀请**，复制配对链接；在另一端选择 **加入设备**，粘贴链接。
4. 核对设备名称，在两端分别确认配对，打开需要被访问电脑上的 **共享这台电脑**。
5. 在设备栏选择执行电脑，打开或新建会话。

双方都启用共享后，可互相操作，无需再次创建反向邀请。详细说明见[使用指南](./docs/双机使用.md)。

## 连接方式

| 方式 | 适用场景 | 准备 |
| --- | --- | --- |
| 局域网直连 | 两台电脑处于可互访的网络 | 默认 TCP 端口 `47321` |
| Workers 中继 | 两台电脑位于不同网络 | [部署一个双方可访问的中继](./docs/Workers部署.md) |

异地连接由两端主动连接中继，无需配置内网电脑的公网入站端口。中继只转发密文，任务始终在所选电脑上执行。

## 共享与权限

共享范围包括执行电脑当前用户的 Codex 项目与会话。任务沿用该电脑已有的审批与沙箱配置；暂停本机共享后，仍可继续操作远端。

Relay 管理独立的 Codex 进程，不接管其他客户端正在运行的任务。网络恢复后不会自动重发任务或审批，提交结果不确定时请先重新读取会话。

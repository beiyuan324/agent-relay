# Relay 0.0.10

## 改进

- 精简工作台、设备列表和输入区的重复文案、计数与页脚，让会话和主要操作更突出。
- 将刷新入口移至会话列表顶部，展开与收起设备栏共用同一个共享开关。
- 会话权限与沙箱信息集中到“会话状态”，对话区仅在离线、接续和异常时显示状态提示。
- 简化设备配对、设置、命令与引用菜单、待发消息及更新界面，保留必要的授权说明和错误反馈。
- 保留图标按钮的无障碍名称，并清理删除元素对应的遗留样式。

## 安装说明

支持 Windows x64。下载 `Relay_0.0.10_x64-setup.exe` 安装；已安装支持自动更新的版本可在设置中检查更新。

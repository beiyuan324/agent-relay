# Relay 0.0.4

## 新增

- 正式安装版启动后自动检查更新，并支持在设置中手动检查。
- 显示更新下载进度和版本说明，下载完成后可选择安装并重启。
- 对更新安装包执行签名及版本校验；安装前保存已生效的设置，并检查运行中的任务、待处理审批和设备请求。
- GitHub 发布流程生成带签名的 Windows 安装包、更新清单和 SHA-256 校验文件。
- 扩展远端审批支持，覆盖会话授权、额外权限申请和工具表单确认。

## 修复与改进

- 区分连接中继、加密握手和配对确认阶段，保留具体连接错误。
- 收到待确认设备时恢复窗口并打开确认界面，避免本机看不到确认入口。
- 更新退出时等待 Relay 管理的 Codex 子进程结束。
- 支持自定义中继域名，并可关闭默认域名及预览入口。

## 安装说明

支持 Windows x64。下载 `Relay_0.0.4_x64-setup.exe` 安装。

0.0.3 及更早版本尚未包含自动更新入口，需要手动安装本版本；之后可在应用内更新。更新保留已保存的设置及配对凭据。安装前请保存未发送草稿，并完成运行中的任务和审批。

异地连接请使用新中继地址重新创建配对邀请；已有配对的旧地址不会跟随默认设置自动迁移。

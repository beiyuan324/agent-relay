# Relay 0.0.6

## 改进

- 会话中的引用显示为可点击的名称标签，支持打开同设备会话、查看引用详情，并折叠附带的引用上下文。
- 技能改为通过 `$` 搜索和选择，插入 `$技能名`；`@` 用于引用文件、目录和应用。
- 工具和命令执行改为紧凑活动行，点击后显示命令、输出、耗时和退出码。
- 点击项目旁的“＋”可直接在项目内创建并打开会话，无需再次选择项目。
- 精简会话列表，在悬停提示中显示更新时间。
- 中继断线时保留当前会话，并在连接恢复后于后台恢复同步。

## 安装说明

支持 Windows x64。下载 `Relay_0.0.6_x64-setup.exe` 安装。

# Relay 0.0.7

## 新增

- 输入 `/` 打开命令与技能菜单，支持筛选、键盘选择和执行；焦点不在输入控件时，按 `/` 可直接唤起。
- 支持计划模式，可用 `/plan` 或 Shift + Tab 切换，计划生成后可点击“实施此计划”。
- 新增上下文压缩、代码审查、会话分叉与重命名、持续目标、账户额度及 MCP 状态等命令。
- 支持执行电脑上的 `/prompts:名称` 自定义提示词，可填写位置参数和命名参数后编辑发送。
- 任务运行时可继续输入并排队，支持编辑、移除、重试及暂停后继续；每条消息保留入队时的模型、推理强度和模式。

## 改进与修复

- 工具活动按类型汇总，处理中显示当前操作，完成后默认收起，支持展开命令、输出和执行用时。
- 优化 PowerShell 命令展示和复制内容，保留完整启动命令供查看。
- 显示上下文窗口用量，优化新会话草稿与会话状态展示。
- 完善 Codex 工具搜索路径，兼容桌面安装附带的工具。
- 修复新会话首条消息后的模式丢失，以及接续响应覆盖较新回合状态的问题。
- 断线时保留已接收的会话内容和草稿，连接恢复后同步状态。

## 安装说明

支持 Windows x64。下载 `Relay_0.0.7_x64-setup.exe` 安装；已安装支持自动更新的版本可在设置中检查更新。新增命令的可用性取决于执行电脑的 Codex 版本和模型配置。

# Relay 0.1.0

## 安卓端首次发布

- 使用手机配对并远程操作电脑上的 Codex。支持局域网与异地连接、会话接续、引用、斜杠命令和审批。
- 安卓支持后台连接、审批与任务结果通知。草稿和待发消息保存在应用私有目录，应用重启后可恢复。

## 消息队列

- 桌面和安卓共用原生调度。等待入队确认时，重复点击发送或连续按回车只提交一次。
- 安卓在同一次写入中保存待发消息和清理原草稿。将待发消息移回输入框编辑时，会保留已有草稿。
- 已发送首轮消息的新会话在应用重启后仍可从列表打开。

## 安装

- Windows x64 下载 `Relay_0.1.0_x64-setup.exe`。已安装旧版的用户可在设置中检查更新。
- Android ARM64 下载 `Relay_0.1.0_arm64.apk`。需要 Android 8.0 或更新版本，以及 Android System WebView 110 或更新版本。

# 双机使用说明

Relay 支持在两台 Windows 电脑之间共享和操作 Codex。

## 各自准备执行环境

两台电脑使用各自 Windows 用户安装并登录 Codex。Relay 按需启动自己的 `codex app-server` 进程，不复制另一台电脑的登录凭据，也不接管官方 Codex 桌面应用的窗口。

启动 Relay 后，欢迎页会显示 Codex 环境状态。路径留空时自动查找安装；设置中的“自动检测”可显示路径和来源，也保留手动选择入口。需要登录时，在**执行电脑**的终端执行 `codex login`。完成后点击会话栏右下角的刷新按钮，重新读取环境、模型、会话和审批。

本机缺少 Codex 不妨碍连接远端已经准备好的 Codex；两台电脑的可用状态独立。

## 局域网连接

1. 两台电脑连接可以互访的网络，在 A 上打开“添加设备 → 创建邀请 → 同一网络”。
2. 选择 B 能访问的 A 网卡地址。默认监听 IPv4 全部网卡的 TCP 47321 端口；有多网卡或 VPN 时可手动输入相应地址。
3. 创建并复制配对链接。B 打开“添加设备 → 加入设备”，粘贴该链接。
4. A、B 分别核对对方名称，在设备详情中确认配对。双方确认之前，Codex 操作不会放行。
5. A 打开“共享这台电脑”，B 就能在设备栏选择 A，浏览并操作 A 的 Codex。
6. 若还要从 A 操作 B，B 也打开共享开关即可，不需要再创建反向邀请。

首次运行时 Windows 可能询问防火墙权限。仅在需要连接的网络范围放行 Relay；不要求手动添加公网端口映射。端口已占用时诊断会说明，异地中继仍可使用。地址发生变化后，当前首版需要重新配对以更新邀请端点。

创建邀请会保留一个待加入设备条目。关闭邀请弹窗不会撤销邀请；不用的邀请在设备详情中取消配对即可。

## 异地连接

按 [Workers 部署说明](Workers部署.md) 准备一个两端均可访问的中继地址。

1. A 选择“创建邀请 → 异地连接”，输入中继根地址。
2. B 加入 A 创建的配对链接；链接已经包含相同中继地址。
3. 连接并完成加密握手后，两端会显示对方设备名称并弹出确认界面；邀请电脑收在托盘时会恢复窗口。双方核对身份并确认配对，在需要被访问的电脑上启用共享。关闭确认弹窗后，仍可点击待确认设备或设备详情继续确认。
4. A 和 B 都主动出站连接 Workers，无需给两台内网电脑配置公网入站端口。

中继收到路由派生值和密文，不接收配对密钥。两台电脑通过同一个加密会话双向传送控制消息。

## 选择会话与项目

- 左栏选择执行电脑；中栏显示该电脑当前用户的 Codex 会话，按项目分组。点击项目标题折叠或展开，状态按设备保存；搜索时暂时展开匹配项目。
- 搜索会话标题，向下可分页加载更多会话。会话不按当前 Relay 仓库过滤。
- 点开历史会话会接续并订阅它；新版本 Codex 使用回合分页，旧协议会尝试历史读取回退。
- 项目旁的“＋”可在该项目下新建会话，自动填入项目路径，创建后展开对应项目。顶部“＋”或 Ctrl+N 可选择其他项目。新建时使用**执行电脑上的绝对目录路径**，由执行电脑验证。
- 工具栏和输入框下方持续显示执行电脑，发送前可确认执行位置。
- 可从执行电脑返回的目录选择模型和推理强度；默认不覆盖主机已有审批和沙箱配置。
- Enter 发送，Shift+Enter 换行；Ctrl+K 搜索，Ctrl+N 新建，Ctrl+, 设置。

选择已有会话无法接续时，应用显示 Codex 返回的错误消息、错误码和附加详情，并尝试只读读取历史。历史读取也失败时会单独说明，已缓存内容可能不完整。此时不能发送消息、停止回合或提交审批，可点击“重试接续”。

Relay 管理独立的 Codex 进程，可接续已保存的会话；不接管其他客户端正在执行的任务。

每轮完成后突出展示最终答复，中间说明、思考与工具调用默认收起，点击用时一行可展开。缺少完整计时数据时显示“用时未知”，估算用时标注“约”。计划正文支持 Markdown 标题、列表、表格和代码块。

## 归档与恢复会话

会话栏直接显示未归档会话；“已归档”位于会话栏底部，默认收起，点击后展开。两份列表均支持项目分组、搜索和分页，归档区独立滚动。

- 在未归档列表中，将鼠标移到会话上，点击右侧的归档图标。选中会话或通过键盘移入该行时也会显示操作按钮。
- 展开底部“已归档”后，打开会话可只读查看历史；点击会话右侧或正文上方的“恢复会话”，会话将移回上方未归档列表，再打开即可继续发送消息。展开或收起归档区不影响当前打开的会话。
- 运行中、正在发送或有待处理审批的会话需先结束任务或处理审批；新会话发送首条消息并生成历史后才可归档。按钮提示会显示不可操作的原因。

归档状态由执行电脑的 Codex 保存，本机与远端使用同一入口。归档父会话时，Codex 也会尝试归档其生成的子会话；恢复操作针对所选会话。界面收到成功响应或状态通知后更新列表；超时或断线时显示实际错误，不自动重试，可刷新确认最终状态。

## 输入框的 @ 引用

在输入框键入 `@`，或点击“引用文件、技能或应用”，打开候选菜单：

- 文件／目录：继续输入文件名，搜索当前会话在**执行电脑**上的项目目录。空查询可先选择当前项目。
- 技能：选择执行电脑上已启用的技能，发送时附带技能名称与路径。
- 应用：选择执行电脑当前 Codex 可以访问且已启用的应用，发送时附带原生应用引用。

使用 ↑↓ 移动选择，Enter 或 Tab 插入，Esc 关闭；Shift+Enter 仍可换行。可继续输入添加多个引用，点击已选引用旁的“×”移除。修改引用文字会撤销其绑定，避免旧应用或技能引用随修改后的文字发送。

文件路径保留为执行电脑路径；跨设备切换不会把本机文件候选带给另一台电脑。菜单会显示接口不支持或候选读取失败的实际原因，可刷新后重试。

## 审批与停止

命令和文件审批支持“拒绝”和“允许这一次”；命令审批会按执行电脑提供的选项展示本次允许、会话内允许、取消或保存规则。额外的网络与文件权限申请可拒绝、仅允许本次回合，或在当前会话内允许。补充输入支持选项和文本回答。

MCP 工具授权支持填写表单后确认、拒绝或取消；需要网页授权时，先完成卡片所示地址中的授权，再点击“已完成，继续”。暂不支持的复杂表单或身份验证仍可拒绝／取消。同一审批在任何一端处理后，其余端的待处理状态会同步移除。

未知审批会展示原始详情并保持待处理，不默认批准。可以停止当前回合，更新 Relay 后再重试。主机现有配置若自动审批某类操作，Relay 不额外插入审批。

运行期间点击“停止”只中断当前回合，不取消设备配对。同一会话中的并发启动会经过 Relay 的串行入口和 Codex 的运行状态检查。

## 暂停、重连与撤销

- 暂停**本机共享**只影响其他设备访问本机；本机仍能操作已共享的远端。
- 已开始的主机任务不因共享暂停而自动终止，暂停后不再允许新的远端操作或继续转发结果。
- 断线时结束等待中的网络请求。重连只恢复通道、设备状态和当前会话订阅，不重发消息、停止请求或审批决定。
- 提交后恰好断线时，结果可能不确定。重新读取会话确认是否已经执行，再决定后续操作。
- 中继告知同配对被另一实例替换时，自动重连停止；在设备详情点击“重新连接”。
- 取消配对立即断开通道，删除本机凭据并移除设备。另一端需要重新配对。
- 系统凭据不可用时保留设备条目并显示“需要重新配对”，不会静默重建密钥。

## 设置与诊断

设备名称、默认中继地址、Codex 路径和外观在设置中管理。改变 Codex 路径会关闭 Relay 管理的旧进程，请先停止运行中的任务。

普通设置由用户配置目录中的 `settings.json` 保存；配对密钥位于 Windows 凭据管理器，服务名为 `app.agent-relay.desktop`。设置文件损坏时保留原文件并报告启动失败，不静默清空已有信任关系。

异地邀请在中继注册完成前显示“正在连接”，注册成功后才显示“等待设备加入”；收到远端连接后显示“正在验证设备身份”，取得设备名称后才进入“等待配对确认”。如果另一端仍显示“正在连接”或“未连接”且没有设备名称，连接还没有进入确认阶段；请查看另一端的设备详情和连接诊断。加密握手、身份交换超时，以及中继注册和网络连接失败都会保留具体错误。

诊断最多保存本次运行的 100 条状态信息，可复制。诊断不记录聊天正文、密钥或登录凭据；会话内容和命令详情只在用户操作的工作台中展示。

## 托盘与退出

点击窗口右上角的“×”或按 Alt+F4，会将 Relay 收起到系统托盘。应用继续运行，设备连接、共享和正在执行的任务保持运行。

点击或双击托盘中的 Relay 图标可恢复主窗口；也可右键图标，选择“显示主窗口”。最小化按钮仍将窗口最小化到任务栏。

需要完全关闭应用时，右键托盘图标并选择“退出 Relay”。退出会断开设备、终止 Relay 管理的 app-server，并保存设置。应用暂不提供开机自启或后台服务。

# 安卓端

Relay 安卓端用于完整操作电脑上共享的 Codex。手机不需要安装或登录 Codex，任务、项目文件和 Codex 登录信息保留在执行电脑。

## 安装与配对

支持 Android 8.0 及以上、Android System WebView 110 及以上。正式安装包面向 ARM64 设备；x86_64 包用于模拟器验收。

1. 在电脑上打开 Relay，准备并登录 Codex，创建局域网或 Workers 配对邀请。
2. 在手机上安装签名 APK，打开“添加设备 → 加入设备”，粘贴邀请。也可以打开收到的 Relay 邀请链接，在应用中确认连接。
3. 两端核对设备名称与标识，分别确认配对；在执行电脑上开启共享。
4. 手机会话列表顶部切换电脑，选择项目和会话，或点击加号新建会话。

手机也可以创建邀请，供电脑加入。邀请包含配对密钥，只分享给自己的目标设备。

## 手机操作

- 首页显示会话与项目，顶部切换执行电脑；进入会话后全屏阅读和输入，返回箭头回到列表。
- 消息输入框回车换行，点击发送按钮提交；运行中继续输入会加入待发队列。使用外接键盘时可通过 Ctrl+Enter 发送。
- 点击输入框下方的模型名称，选择模型、推理强度和计划模式。文件、技能、应用引用及全部斜杠命令沿用电脑端。
- 审批提示可展开为独立面板，阅读完整命令、文件修改、权限或补充输入要求后处理。
- 文件变更、归档恢复、自定义命令、代码审查、会话分叉、持续目标、账户额度和 MCP 状态均使用同一套业务实现。
- 草稿、引用和待发消息保存于手机应用私有目录。应用重启后恢复内容，并暂停待发队列；同步会话后再继续。上次结果未知的发送不会自动重发。

## 后台与澎湃 OS

在“设置 → 后台与通知”开启后台连接，允许通知。应用通过常驻通知维持连接，并提醒待处理审批和任务结果；点击通知回到对应会话。通知内容默认不包含命令或正文。

小米澎湃 OS 建议同时允许 Relay 后台自启动，并将电池策略设为“不限制”。设置页提供相关系统入口；其他品牌通过应用详情和电池设置调整后台策略。

可从常驻通知停止后台连接。系统强行停止应用后，重新打开 Relay 会恢复草稿和暂停的待发队列。首版没有接入应用被终止后的厂商推送。

## 更新

正式版本可在应用内检查、下载安装更新。Relay 验证 HTTPS 来源、SHA-256、应用标识、递增版本号及签名证书，再交由安卓系统确认安装；首次安装更新需要允许 Relay 安装应用。取消系统安装后，可以返回设置再次安装。

开发验收包使用单独应用标识，不自动更新为正式版。正式升级保留原配对与草稿，卸载应用会清除这些本地数据。

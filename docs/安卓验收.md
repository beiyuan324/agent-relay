# 安卓实现与验收记录

验收日期：2026-11-19。版本：0.0.10。安卓应用用于远程操作电脑上的 Codex。

## 实现范围

React 业务组件、项目分组、消息与变更展示、引用、全部现有斜杠命令、审批表单及 Rust 配对、加密和网络协议由两端共用。待发队列迁入共享原生核心，手机和桌面只有一套发送调度。安卓原生层负责前台服务、通知、Keystore、安全区、返回操作、权限和 APK 安装更新。

PC 的本机执行、共享本机、托盘和窗口控制保留在桌面端；安卓以设备选择、常驻通知和系统返回操作提供对应移动入口。任务实际在所选电脑执行。

| --- | --- | --- |
| 配对、确认、取消、重连 | 共用协议，支持邀请链接与系统分享 | 模拟器完成局域网加密配对、双方确认和重启重连 |
| 项目与历史 | 共用分组、搜索、分页、新建、接续、归档恢复 | 模拟项目与会话可打开；归档、搜索等共用既有路径 |

| Windows | 共用核心和业务界面，保留桌面系统能力 | 回归测试与 NSIS 安装包构建通过，未安装覆盖用户当前桌面版 |

## 自动验证

- 前端：21 项测试通过，覆盖已有工作台回归、原生入队失败、队列快照顺序、手机回车、桌面回车和中文组合输入。
- Rust 工作区：22 项测试通过，包括原有网络、加密、进程与持久化测试，以及 8 项新增队列测试。
- 新增队列测试使用独立加密假电脑，覆盖无 WebView 调度、完成事件早于响应、审批等待、过期审批快照、新会话整体迁移、提交结果未知不重发、持久化失败及重启恢复。
- 前端生产构建、Windows NSIS 构建、Android x86_64 开发包和 ARM64 签名发布包构建通过。
- 发布 APK 通过 apksigner 验证、16 KB ZIP 对齐；ARM64 原生 ELF 加载段对齐为 0x4000。

## 实测环境和待验收项

已使用 Android 15／API 35 的 MuMu 模拟环境，包含 ARM64 翻译运行和 x86_64 原生运行，以及 WebView 110。模拟器报告的厂商品牌不能替代相应品牌真机。

系统最低版本为 Android 8.0／API 26，编译和目标版本为 API 36，原生库由 NDK 28.2 构建。当前 SDK 仓库未提供稳定 API 37 平台包；代码包含相应的局域网权限条件处理。

仍需使用真机验证 HyperOS、One UI、ColorOS、OriginOS、MagicOS 的后台电池策略、锁屏长时间连接、真实 Wi-Fi／移动网络切换与通知行为。当前模拟输入法报告已显示，但未实际呈现软件键盘面板，因此软件键盘遮挡和完整中文输入法体验仍列为真机验收项。模拟器中的回车换行与组合输入逻辑已有实际或自动测试覆盖。

未运行应用商店上架、厂商推送注册或生产中继部署；本次交付为本地签名 APK、代码和构建配置。

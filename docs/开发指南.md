# 开发指南

Relay 使用 Rust + Tauri 2 构建桌面应用，界面采用 React、TypeScript 和 Vite。当前开发目标为 Windows。

## 环境准备

- Node.js 22+ 与 npm。
- Rust MSVC 工具链。
- Visual Studio C++ Build Tools。
- Microsoft Edge WebView2 Runtime。
- 本机 Codex 安装及登录配置，用于运行实际会话。

Relay 在未手动指定路径时自动查找 Codex，覆盖：

- 当前 PATH，以及 Windows 用户／系统注册表中持久化的 PATH。
- `%LOCALAPPDATA%/OpenAI/Codex/bin/<版本目录>/codex.exe` 与已知桌面资源目录。
- npm 全局安装、nvm／pnpm 的常见目录和配置的 Volta 安装目录。
- 当前用户的 VS Code、VS Code Insiders、Cursor 和 Windsurf 中官方 Codex 扩展的 CLI。
- 用户的 `.cargo/bin`、`.local/bin` 和 Scoop／WinGet 常见入口。

设置里的“自动检测”会显示找到的路径和来源，成功后恢复路径留空的自动模式；点击“完成”保存。扫描只读取已知目录，不启动 Codex 或遍历整块磁盘。自动检测失败时仍可手动选择 `codex.exe`、`codex.js` 或 npm 的 `codex.cmd/ps1`；npm 启动脚本会解析到实际入口，优先使用原生二进制，只有 JavaScript 入口时才需要 Node.js。

应用不会自动安装或登录 Codex，也不会接管官方桌面应用内置的私有进程。

## 启动桌面应用

在仓库根目录执行：

```powershell
npm install
npm run desktop
```

Tauri 会启动 Vite 开发服务器和 Rust 桌面进程。

## 预览界面

```powershell
npm run dev
```

浏览器预览只展示界面与空状态，不连接本机或远端 Codex。设备配对、系统凭据和 Agent 操作需要在 Tauri 桌面应用中使用。

## Windows 打包

```powershell
npm run bundle
```

当前配置生成 NSIS 安装包，输出目录为：

```text
target/release/bundle/nsis/
```

Rust workspace 位于仓库根目录。安装包尚未配置代码签名证书。Mac/Linux 的部分平台适配保留在源码中，但当前不提供对应的发布配置。

公开发布前，在仓库根目录的 PowerShell 中重映射编译路径，避免程序包含本机用户名和源码绝对路径：

```powershell
$relaySourceRoot = (Get-Location).Path
$env:CARGO_ENCODED_RUSTFLAGS = @(
  "--remap-path-prefix=$env:USERPROFILE=/build/user",
  "--remap-path-prefix=$relaySourceRoot=/build/agent-relay"
) -join [char]0x1f
npm run bundle
```

该命令会使 Cargo 使用新的编译参数重新构建依赖。发布时附上安装包和 SHA-256 校验文件；不要将登录、设备配置或配对链接加入仓库与 Release。

## 项目结构

```text
agent-relay/
├── crates/relay-core/     # 加密、连接、双向控制与 Codex 适配
├── src-tauri/            # 桌面命令、系统凭据、设置与打包
├── src/                  # React 工作台与交互
├── public/               # 应用静态资源
├── workers/relay/        # Cloudflare Workers 中继
└── docs/                 # 使用、部署和开发指南
```

### Rust 内核

| 文件 | 职责 |
| --- | --- |
| `crypto.rs` | relay-e2e/v1 密钥派生、握手确认、加密与防重放 |
| `net.rs`、`tunnel.rs` | 局域网 WebSocket 与 Workers 隧道 |
| `host.rs` | 设备信任、共享状态、双向请求与连接恢复 |
| `codex.rs` | app-server 进程、会话、事件与审批 |
| `discovery.rs` | Codex 安装位置、npm 原生入口和 Windows PATH 检测 |
| `remote.rs`、`relay.rs` | 加密控制消息、分片与配对邀请 |
| `model.rs` | 设备、设置与消息类型 |

连接层负责配对、加密与双向请求；Codex 适配层负责 stdio 会话与审批；Tauri 层提供桌面命令、系统凭据和窗口能力。界面中的设备及会话状态始终按执行电脑隔离。

## 设置与凭据

普通设置保存为 `settings.json`，所在目录由 `directories::ProjectDirs` 按系统和当前用户确定。

配对密钥通过系统凭据管理器存储，服务名为 `app.agent-relay.desktop`，凭据名称使用每对设备的 UUID，不写入设置文件。各电脑独立维护 Codex 登录、设备信任与共享状态。

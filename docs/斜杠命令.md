# 斜杠命令与计划模式

在会话输入框开头输入 `/`，即可打开命令和技能菜单。继续输入英文命令名或中文说明可筛选，使用 ↑ / ↓ 选择，Enter 或 Tab 执行，Esc 关闭。也可点击输入框下方的“/ 命令”；焦点不在文本输入控件时，直接按 / 也会唤起菜单并保留已有草稿。中文输入法选词期间，Enter 不会执行命令或发送消息。

命令始终作用于当前选择的执行电脑与会话。远端会话的技能、自定义提示词、模型、额度和 MCP 状态都从远端读取。

## 计划模式

- 输入 `/plan`、点击模式按钮或按 Shift + Tab，在默认模式和计划模式之间切换。
- `/plan on` 开启，`/plan off` 或 `/plan default` 关闭。
- `/plan 任务描述` 会直接以计划模式发送这项任务。
- 计划模式通过 Codex 的协作模式协议启用，采用 Codex 内置的计划指令。
- Codex 生成计划后，可以点击“实施此计划”，以默认模式发送实施请求。
- 模式按会话保存；消息入队时固定模式、模型、推理强度和服务档位，后续切换不会改变已排队的消息。

执行电脑需要提供 `collaborationMode/list`。不支持时菜单显示原因，普通会话仍可使用。

## 可用命令

| 命令 | 操作 |
| --- | --- |
| `/plan` | 切换计划模式 |
| `/compact` | 调用 Codex 压缩当前会话的上下文 |
| `/model [模型 ID]` | 打开模型选择，或直接切换到指定模型 |
| `/reasoning [强度]` | 选择推理强度；`default` 使用模型默认 |
| `/fast [on\|off]` | 切换模型目录提供的 Fast 档位 |
| `/review [审查说明]` | 审查未提交修改、基础分支、指定提交或自定义内容 |
| `/new` | 在相同项目中新建会话 |
| `/fork` | 复制当前会话历史到新会话 |
| `/rename [名称]` | 修改当前会话名称 |
| `/archive` | 归档会话，可从归档列表恢复 |
| `/goal [目标内容]` | 设置或管理持续目标，可指定 Token 预算并暂停、继续、清除 |
| `/status` | 查看会话 ID、项目、模型、模式、上下文和账户额度 |
| `/usage` | 查看当前执行电脑账户的额度与重置时间 |
| `/mcp` | 查看 MCP 服务连接、认证状态、工具和资源数量 |
| `/init [补充要求]` | 请求 Codex 编写或完善项目的 AGENTS.md |
| `/skills` | 打开项目技能选择 |
| `/apps` | 打开已连接应用的引用选择 |
| `/project` | 选择项目并新建会话 |
| `/settings` | 打开 Relay 设置 |
| `/feedback` | 打开 Relay 连接诊断 |
| `/help` | 查看命令帮助及当前不可用的原因 |

压缩、审查、分叉和归档需要等待当前回合结束、处理完审批和待发消息；首次发送前尚无持久历史的会话也会提示限制。压缩和审查的进度、完成记录及错误显示在会话中。命令不会作为普通聊天文字发送给模型，`/init` 和带任务描述的 `/plan` 会转换为对应的用户请求。

可用能力取决于执行电脑的 Codex 版本和模型目录。Relay 当前通过本机与配对主机的 app-server 提供命令，不提供 Codex 云执行、Git worktree 管理、桌面宠物或 IDE 上下文等宿主功能。

## 技能和自定义提示词

当前项目启用的技能会和内置命令一起出现在 `/` 菜单。选择技能后会插入结构化技能引用，仍可继续补充任务描述再发送，也可使用原有的 `$技能名` 入口。

自定义提示词读取执行电脑的 `CODEX_HOME/prompts/*.md`；未设置 `CODEX_HOME` 时使用该电脑用户目录下的 `.codex/prompts`。例如 `review.md` 对应 `/prompts:review`。支持 UTF-8 文件和简单的 Markdown frontmatter：

```markdown
---
description: 审查指定功能
argument-hint: FEATURE="功能描述"
---
请审查 $FEATURE，并关注 $1。
```

可输入 `/prompts:review FEATURE="登录流程" 安全性`。支持 `$ARGUMENTS`、`$1` 到 `$9` 以及大写命名参数；包含空格的参数用引号包围。参数不足时打开参数输入窗口。展开结果会放入输入框，可修改后再发送。

每个提示词最大 128 KiB，最多读取 256 个文件，总大小限制为 2 MiB；单个文件读取失败不会影响其他命令。

## 状态与失败处理

会话重命名、目标更新、计划步骤和上下文压缩通过 Codex 通知更新。本地草稿和会话内选择在切换设备时分别保存。网络中断或命令超时不会自动重试；重新读取会话确认结果后再继续。旧版 Codex 不支持新增接口时会显示错误，不会把失败的命令转成普通消息。
